# Handoff

`src/model.js` owns the 10×20 playfield, seven pieces, seeded/injected source, no-kick rotation, lock/clear/score and restart. `src/render.js` produces one pure 24-line frame. `src/gravity.js` owns the single 1000 ms timer. `src/input.js` buffers split escape sequences and recognizes raw Ctrl-C. `src/index.js` exports `start({input, output, scheduler, source, seed, signals})` and is also the `npm start` entry. Interactive output clears and redraws from home without a trailing newline; below 50×24 it shows only a width-limited warning (or nothing at zero dimensions), then restores the current frame on resize. Non-TTY output receives one static frame; non-TTY input with TTY output receives a size-checked static frame or warning (nothing at zero size), then exits. Quit, signals, stream errors and failed redraws remove listeners/timer, restore the original raw state and cursor; close is idempotent. A raw-mode call that mutates state then throws is also restored. Synchronous quit during resume or output error during cursor hide aborts remaining startup (no late gravity timer). Tests are in `test/*.test.js`, especially `test/session.test.js` for lifecycle and resize.

Verification recipes: `node --test test/session.test.js` (13 passed); `npm test` (42 passed). PTY smoke: Python `pty.openpty()`, set 50×24 with `TIOCSWINSZ`, run `subprocess.Popen(['npm','start'], stdin=slave, stdout=slave, stderr=slave)`, wait for `Q: quit`, send `q` through master, verify exit 0 and `\x1b[?25h`; passed. Non-TTY `npm start` is covered by the suite. Avoid npm banners when capturing bounded frames; invoke `node src/index.js` or silent npm instead.
