# Tetris implementation approach

The target is an empty Node.js project (no package manifest, source files, or installed dependencies). Use Node's built-in APIs rather than adding a rendering dependency: draw a fixed 10-column by 20-row board with ANSI cursor positioning and colors, and read keyboard input in raw stdin mode. This keeps the display compact and the project dependency-free. The entry point and `npm start` script will be added with the implementation tasks.
